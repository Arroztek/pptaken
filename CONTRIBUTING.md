# Contributing to PPTaken

Thanks for your interest! The project is in its earliest phase, so the best contributions right now are
bug reports, ideas and feedback on the design documents in `docs/foundation`.

## Ground rules

- Code, identifiers, comments and commit messages are written in **English**.
- Be kind: see the [Code of Conduct](CODE_OF_CONDUCT.md).
- Security issues: do **not** open a public issue. See [SECURITY.md](SECURITY.md).

## Workflow

1. Open an issue before large changes so we can agree on the approach.
2. Fork, create a branch, make your change with tests.
3. Run `pnpm check` locally; it must pass.
4. Open a pull request describing what and why.

## Contributor agreement

Before we accept the first external pull request, a Contributor License Agreement (CLA) will be in
place so the maintainer can also use contributions in the hosted service. The CLA does not transfer
your authorship. Details will be published here before the first public release.
