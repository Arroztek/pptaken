# Getting help with PPTaken

Thanks for using PPTaken! Here is where to go for each kind of request.

- **Questions and how-tos**: open a thread in [GitHub Discussions](https://github.com/arroztek/pptaken/discussions).
- **Bugs**: open an issue using the [bug report template](https://github.com/arroztek/pptaken/issues/new/choose), with steps to reproduce.
- **Feature ideas**: open a [feature request](https://github.com/arroztek/pptaken/issues/new/choose) or start a discussion first.
- **Security vulnerabilities**: do not open a public issue. Report them privately through [GitHub security advisories](https://github.com/arroztek/pptaken/security/advisories/new).

## Best-effort support

PPTaken is maintained by volunteers. Support is provided on a best-effort basis, with no guarantees about response times or fixes. Clear questions, minimal reproduction steps and helpful context make it much easier for the community to help you.
