# Security policy

PPTaken executes content generated by AI agents, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting
(Security tab → "Report a vulnerability") once the repository is public. A dedicated contact address
will be published here before the first public release.

We aim to acknowledge reports within 3 working days.

## Supported versions

There are no supported releases yet (pre-0.1).
